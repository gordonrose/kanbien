# Bad Demo Page Artifact Summary

This is bad because it looks like proof while quietly becoming a new local
implementation.

## Bad Shape

- Rebuilds pattern rows and detail slots inside the demo route.
- Adds demo-only event handlers for primitive events instead of attaching the
  component controller.
- Uses proof controls that do not change any required evidence.
- Invents route-specific filters, backend query behavior, or app navigation.
- Treats copied demo CSS and fixture helpers as the path app pages should use.
- Says accessibility is covered because the component was already accessible,
  without rendered keyboard, focus, state, or live-feedback evidence.

## Why It Fails

The demo no longer proves the shared seam. It creates a second implementation
and invites later app adoption to copy the wrong source of truth.
