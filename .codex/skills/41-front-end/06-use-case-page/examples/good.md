# Good Use-Case Page Artifact Summary

This artifact defines an `entity-list-page` use-case family.

It consumes accepted `record-list-component`, filter controls, and page-header
component seams through their runtime exports.

It maps a representative feature projection into those seams, names fixture
honesty requirements, records page-local state boundaries, and keeps backend
query semantics and durable route topology out of Layer 6.

It includes rendered evidence for responsive layout, keyboard operation,
selection, empty state, loading pressure, direction, zoom, and accessibility
feedback.

It forbids later consumers from copying use-case route markup, CSS, proof-only
controls, or fixtures.
