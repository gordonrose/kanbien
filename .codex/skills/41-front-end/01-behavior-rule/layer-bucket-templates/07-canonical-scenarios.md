# Layer 7 Canonical Scenarios Behavior Bucket

Use this bucket when the ask is for durable review or regression evidence cases.

## Recognition Test

The ask is about stable screenshot scenarios, fixture coverage, or regression-proof review dimensions for states that would cause rework if missed.

## Information Needed

- Demo route
- Component seam
- Pattern contract
- Required states
- Viewport and theme dimensions
- Data-volume cases
- Fixture constraints
- Assertion or screenshot purpose

## Things That Do Not Belong

New behavior, new primitives or tokens, demo implementation details, app adoption, convenience fallback data that production cannot provide.

## Behavior Rule Output Needed

Record the canonical-scenario ask as a later-layer dependency or next step. Name missing information as a blocker. Do not define canonical file names, fixtures, or screenshot scenarios inside the behavior rule.
