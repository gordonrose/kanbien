# Layer 8 First App Adoption Behavior Bucket

Use this bucket when the ask is to apply an already-governed seam to one real app surface.

## Recognition Test

The ask depends on real app route context, data shape, and visibility rules, and must consume the governed seam without local recreation.

## Information Needed

- Signed component seam
- Canonical scenarios
- Target app surface
- Real data shape
- Route context
- Visibility or authorization constraints
- Import boundaries
- Adapter needs

## Things That Do Not Belong

New design-system behavior, app-page CSS for governed presentation, copied demo markup, copied controller logic, local workaround for a missing seam capability.

## Behavior Rule Output Needed

Record the app-adoption ask as a later-layer dependency or next step. Name missing information as a blocker. Do not define app imports, wrappers, CSS, or adoption implementation inside the behavior rule.
