# Layer 4 Pattern Contract Behavior Bucket

Use this bucket when the ask is for a reusable composition with structure, slots, state ownership, data expectations, or consumer customization rules.

## Recognition Test

The ask describes a reusable pattern larger than a primitive and needs a contract to prevent downstream approximation.

## Information Needed

- Accepted behavior rule
- Required primitives and tokens
- Representative data shape
- Required states
- Consumer context
- Accessibility behavior
- Customization boundaries

## Things That Do Not Belong

Low-level primitive invention, new token values, implementation-specific import paths, demo route controls, app route adoption, visual regression scenario lists.

## Behavior Rule Output Needed

Record the pattern ask as a later-layer dependency or next step. Name missing information as a blocker. Do not define pattern slots, data contracts, or composition details inside the behavior rule.
