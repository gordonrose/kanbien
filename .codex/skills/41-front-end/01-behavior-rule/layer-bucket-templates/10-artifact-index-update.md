# Layer 10 Artifact And Index Update Behavior Bucket

Use this bucket when the ask is to align maintained references after layer work.

## Recognition Test

The ask is about updating indexes, inventories, generated artifacts, or closeout notes, not creating UI behavior or claiming unpassed gates.

## Information Needed

- Completed layer outputs
- Passing eval evidence
- Maintained indexes affected
- Generated artifact commands
- Stale references
- Deferred or blocked gates

## Things That Do Not Belong

New behavior, new pattern decisions, source implementation changes, claiming full adoption when a required gate is blocked, manual edits to generated files without the approved command.

## Behavior Rule Output Needed

Record the index/update ask as a later-layer dependency or next step. Name missing information as a blocker. Do not update indexes or generated artifacts from the behavior-rule skill.
