# Layer 5 Component Seam Behavior Bucket

Use this bucket when the ask is about how consumers will use a governed pattern without copying markup, styling, controller behavior, or fixture logic.

## Recognition Test

The ask needs a named consumable seam shared by design-system review surfaces and app adoption.

## Information Needed

- Accepted pattern contract
- Target consumer contexts
- Export conventions
- Import boundaries
- Controller responsibilities
- Data adapter requirements
- Accessibility preservation rules

## Things That Do Not Belong

New pattern behavior, token invention, demo-only controls, app-local wrappers that recreate the seam, route-specific business logic.

## Behavior Rule Output Needed

Record the seam ask as a later-layer dependency or next step. Name missing information as a blocker. Do not define props, adapters, import paths, or runtime APIs inside the behavior rule.
