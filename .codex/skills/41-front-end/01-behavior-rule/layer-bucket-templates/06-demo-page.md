# Layer 6 Demo Page Behavior Bucket

Use this bucket when the ask is to make a governed seam visible and reviewable.

## Recognition Test

The ask is for a design-system review surface, not for defining the contract or adopting the pattern into the app.

## Information Needed

- Component seam
- Pattern contract scenarios
- Representative fixtures
- Required states
- Viewport requirements
- Theme and direction requirements
- Interaction evidence needed

## Things That Do Not Belong

Source-of-truth behavior, app-specific data handling, copied seam markup, route-local behavior absent from the seam, broad exploratory playground controls.

## Behavior Rule Output Needed

Record the demo ask as a later-layer dependency or next step. Name missing information as a blocker. Do not define demo routes, demo controls, or visual proof cases inside the behavior rule.
