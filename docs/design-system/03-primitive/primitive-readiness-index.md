This index prevents primitive templates, examples, route-local markup, or app
fragments from being mistaken for governed primitive contracts.

A primitive is consumable by later layers only when it has a review-ready or
accepted shared primitive contract, any required system proof for the selected
design system, and signed token dependencies for that system.

## Template Only Or Not Yet Created

The Layer 3 harness is active. Generic `checkbox` and generic `switch` are
still not consumable as broad primitives. `toggle-control` is consumable only
for one governed boolean on/off setting, not checkbox lists, multi-select,
radio, dropdown, or workflow-builder behavior. `radio-simple-select` is
consumable only for simple native single-choice radio groups, not for generic
card-list prioritization, multi-select, toggle, dropdown, or workflow-builder
behavior. `simple-dropdown-control`
is consumable only for compact single-select listbox behavior, not search,
autocomplete, multi-select, drawer select, card-list prioritization, or workflow-builder behavior.

`index-nav-panel-header-control` remains family-scoped because its header
geometry and sticky behavior still consume `index-nav-panel-frame`.

## Update Rule

When a primitive moves out of template-only or missing status, update this index
in the same change as the shared primitive contract, any system proof artifact,
runtime seam planning or implementation, and focused verification evidence.
