## Proof Scope

This proof shows a labelled body-region host consuming the signed
`body-region-frame` token and composing the governed `scroll-region-control`
primitive.

It intentionally uses proof-only placeholder content. It does not govern text
fields, text areas, selectors, accordions, workflow builders, validation copy,
or product data.

The proof route exposes controls for state, mobile scroll mode, and content
pressure so reviewers can inspect the primitive boundary in the browser.
