# Focus Instruction Disclosure Default Proof

Layer: `03-primitive`
System: `default`
Status: `review-ready`

Rendered view:
`/design-system/default/primitives/focus-instruction-disclosure`

The default proof renders the shared `focus-instruction-disclosure` primitive
using signed `tooltip-surface` and `tooltip-text-style` token seams.

The proof demonstrates a focused reorder instruction, a focused selection
instruction, a constrained host, and dark/desert theme surfaces. The host
control keeps focus while the instruction appears through `aria-describedby`.
