## Proof Scope

This proof shows that the default design system can render the generic panel
header primitive using signed `panel-header-frame`, `label-text-style`,
`icon-button-control`, and `truncating-label` seams.

It does not prove panel body layout, embedded secondary navigation, mobile
takeover behavior, or hosted form controls.
