## Proof Scope

The default proof demonstrates original, dark, and desert skins using the
signed token dependencies named by the shared primitive contract.

The proof may change visual values only through signed token seams. It must not
change button behavior, focus behavior, current semantics, disabled behavior, or
the event contract.
