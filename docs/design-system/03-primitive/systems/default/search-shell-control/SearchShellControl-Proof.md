# Search Shell Control Default Proof

Shared contract:
`docs/design-system/03-primitive/shared/search-shell-control/SearchShellControl-Contract.md`

Rendered view:
`/design-system/default/primitives/search-shell-control`

The default proof renders desktop empty, active, compressed, mobile full-width,
RTL, and localized placeholder states. It composes the governed
`search-field-control` primitive instead of rebuilding native input behavior.

The proof does not approve search results, route query state, backend search,
component props, or app adoption.
