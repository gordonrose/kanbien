# Asset Consumer Decisions

This folder stores asset consumer decision records.

Repo bucket classification: `shared-governance-kernel`, with subject-specific
platform or feature ownership per record.

Asset consumer decisions are security, privacy, authorization, cost, delivery,
cleanup, and operations gates for features that upload, read, link, display,
download, replace, delete, publish, or deliver user-managed assets.

These records are active only when reconciled with the current PRD, API
contract, data dictionary, permission mapping, runbook, security tests, and
technical signoff for the consuming feature.

Before treating a record as implementation authority, check whether it is:

- draft
- approved for planning
- approved for task breakdown
- technically signed off
- superseded
- historical

Do not archive or move this folder without updating `AGENTS.md`, asset decision
templates, standards references, and downstream feature artifacts that cite
these records.
