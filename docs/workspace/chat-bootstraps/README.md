# Chat Bootstraps

This folder stores material-work start records for repo-local Codex sessions.

Repo bucket classification: `shared-governance-kernel`.

Chat bootstraps are active git/workflow evidence. They record the intended
branch, base commit, worktree, write set, shared seams, and non-goals before a
material edit loop proceeds.

Current producers and consumers include:

- `AGENTS.md`
- `docs/standards/git-workflow-guardrails.md`
- `src/scripts/codexTask.ts`
- `src/scripts/codexSplit.ts`
- `src/scripts/lib/codexTaskRegistry.ts`
- `src/scripts/gitPreflight.ts`

Do not archive or move this folder without updating those script defaults,
standards references, and task-breakdown examples.

Individual bootstrap records are point-in-time evidence. They do not prove a
task is still active, complete, or safe to promote without a fresh git
preflight, task-registry, or branch/worktree audit.
