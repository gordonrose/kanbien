# OpenAPI Foundation

## Current Status

- `present`

## What This Layer Should Do

- document route surface in a machine-readable API format
- support discovery, review, and client/tooling compatibility
- complement but not replace richer human-readable contract docs

## Implemented To Date

- `docs/swagger/openapi.yaml` covers current root-auth and root-users routes
- OpenAPI is part of the current artifact chain and skill workflows

## Still Missing / Next Steps

- keep it synchronized as more features and route families arrive
- decide later whether contract manifests should become more formalized
