# Artifact Alignment

This folder stores dated, one-off alignment inventories and reconciliation notes
for planning artifact chains.

Use this folder for:

- inspected artifact-chain inventories
- source-of-truth alignment findings
- migration or containment recommendations that need later human decision
- closure-sweep evidence for Product Request, Story Breakdown, Task Breakdown,
  PRD, implementation-blueprint, or related workspace artifacts

Do not use this folder as the durable source of artifact-chain rules. Current
rules belong in the owning templates, skills, standards, architecture docs, or
active Product Request packets.

Before treating an older alignment inventory as current, re-check the referenced
artifacts, validators, and downstream task records. These notes may contain
useful unresolved findings without being current operating authority.
