# Reviews

This folder stores point-in-time repo review evidence.

Repo bucket classification: `shared-governance-kernel`.

Use this folder for:

- AI-assisted change review notes
- standards-sensitive closeout reviews
- source-alignment or compliance review notes

Reviews are durable governance evidence, but they are scoped to the source,
artifacts, and date named in the review. Do not treat a review as current
implementation truth without checking the source and any follow-up findings.

- `.codex/skills/10-repo-governance/ai-change-reviewer/SKILL.md`

Do not move this folder without updating review skills, standards references,
and any story/task closeout artifacts that cite review files.
