# Frontend Workspace Breadcrumb

The mixed frontend workspace folder has been split.

Current locations:

- `docs/workspace-buckets/archive-history/frontend/`
  for historical frontend migration plans
- `docs/workspace-buckets/frontend-harness/entity-management/`
  for active frontend-harness recovery and governance notes
- `docs/workspace-buckets/platform/page-shell-planning/`
  for platform feature planning that depends on frontend-harness seams

Do not add new mixed frontend plans here. Place new records in the owning
bucket or in an active governed frontend-harness folder with a clear contract.
