# Token Foundation Seams Canonical Rendering Exception

Approved canonical rendering exception.

## Decision

`token-foundation-seams` may claim `system-ready` through the signed-off token
routes listed in its reference pack before generated
`/design-system/canonical-renderings/token-foundation-seams` pages exist.

## Boundary

This exception applies only to the aggregate token foundation promotion pass.
Future extracted component families should use generated canonical render pages
unless an equally explicit exception is approved.
