# Page Background Canonical Rendering Exception

Approved canonical rendering exception.

## Decision

`page-background` may claim `system-ready` through the signed-off background
token route and token foundation seam artifact set before generated
`/design-system/canonical-renderings/page-background` pages exist.

## Boundary

This exception applies only to the current environmental token seam. If the
background token gains high-risk visual states beyond the token editor, promote
those states into generated canonical render pages.
