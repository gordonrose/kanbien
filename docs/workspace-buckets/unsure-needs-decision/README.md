# Unsure Needs Decision Bucket

This bucket is for inspected artifacts whose current owner, authority, or
freshness cannot yet be classified confidently.

Use it only when:

- the file has been inspected
- current references or source authority are ambiguous
- moving it directly to another bucket would create fake certainty
- a future decision note can explain what remains unresolved

Do not use it as a permanent dumping ground. Each artifact placed here should
name the decision needed before promotion, archival, or relocation.

Before moving legacy files here, leave a breadcrumb at the old path and record
the ambiguity that prevented a stronger classification.
