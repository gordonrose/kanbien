# Archive History Bucket

This bucket is for retained historical records.

Use it for:

- superseded planning notes
- completed task-run or audit evidence kept only for traceability
- historical snapshots, old examples, and retired design notes
- retired blog drafts, outlines, and communication workflow notes
- retired delivery pilots whose rules have moved into active harnesses
- retained delivery retrospectives and lesson notes
- older workspace archive material retained for traceability
- historical harness snapshots retained for reconciliation and rollback
- historical harness audits and reconciliation notes
- historical frontend migration plans
- historical traceability and semantic-test audit notes
- historical artifact-chain alignment inventories and reconciliation notes
- stale historical permission mapping CSV exports retained for provenance
- historical imported source files retained for provenance after conversion
- records useful for learning or reconstruction but not current source truth

Do not use it for:

- active guardrail inputs consumed by scripts or tests
- current templates, standards, skills, or architecture decisions
- unresolved cleanup notes that still block current work

Before moving legacy files here, verify they are no longer active inputs. Leave
a breadcrumb at the old path when older docs, chats, or skills may still point
there.
