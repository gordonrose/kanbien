# Archived QA Evidence

This folder holds QA records that remain useful as provenance, examples, or
point-in-time feature-loop evidence but are no longer active QA operating
authority.

Old paths under `docs/workspace/qa/` may keep short breadcrumbs during the
repo-bucket cleanup so existing links have a route to the archived record.

Do not add active waivers, security matrices, release gates, or current QA
backlogs here directly.
