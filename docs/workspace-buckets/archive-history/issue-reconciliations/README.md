# Archived Issue Reconciliations

This folder holds issue-reconciliation records whose prevention lessons have
been promoted into active tests, skills, standards, verification artifacts, or
runtime guardrails.

The old paths under `docs/workspace/issue-reconciliations/` keep short
breadcrumbs so existing links have a route to the archived provenance.

Do not add new escaped-defect records here directly. New issue reconciliations
start in `docs/workspace/issue-reconciliations/` and move here only after a
freshness or supersession pass.
