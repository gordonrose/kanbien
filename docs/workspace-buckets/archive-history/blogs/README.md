# Archived Blog Drafts

This folder preserves historical draft blog ideas and outlines that grew out of
the work in this repo.

Repo bucket classification: `archive/history`.

These files are communication memory, not active platform, discovery-harness,
frontend-harness, or shared-governance source truth.

Use it as retained reference for:

- article ideas worth developing later
- outline-first drafts
- talking points tied to real delivery work
- notes on audience, angle, and supporting repo artifacts
- repeatable prompts and workflows for turning weekly repo progress into posts

Keep these as historical drafts rather than polished marketing copy.

Recommended naming:

- `YYYY-MM-DD-<topic>-ideas.md`
- `YYYY-MM-DD-<topic>-outline.md`

Examples:

- `2026-04-08-engineering-blog-ideas.md`
- `2026-04-08-notification-delivery-outline.md`
- `2026-04-08-blog-accountability-workflow.md`
