# Frontend Harness Bucket

This bucket is for governed frontend lab and design-system artifacts.

Use it for documentation that governs or describes:

- design-system tokens, primitives, patterns, canonicals, and components
- behavior locks, reference packs, verification evidence, and adoption notes
- visual/browser proof surfaces for governed frontend families
- frontend topology or app-adoption plans that are still frontend-harness owned

Do not use it for:

- real app UI implementation plans that bypass design-system signoff
- backend API, persistence, or permission truth
- Product Discovery interview or planning packet templates
- historical frontend notes that are no longer active guidance

Before moving legacy files here, inspect references from frontend skills,
visual tests, design-system routes, and planning artifacts. Leave breadcrumbs
when old paths may still be used.
