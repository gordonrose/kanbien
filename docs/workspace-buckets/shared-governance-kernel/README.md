# Shared Governance Kernel Bucket

This bucket is for repo-wide rules, guardrails, evidence, and coordination
records that apply across workstreams.

Use it for documentation that governs or describes:

- repo health, standards compliance, and architecture-map coordination
- git workflow, branch/task lifecycle, and cross-chat safety
- decision evidence, QA evidence, issue reconciliation, reviews, and audits
- agent instruction architecture and reusable governance behavior

Do not use it for:

- feature-owned backend implementation truth
- Product Discovery packet content that belongs to the discovery harness
- design-system family artifacts that belong to the frontend harness
- passive historical records that no longer influence active decisions

Before moving legacy files here, inspect references from scripts, skills,
standards, tests, and existing docs. Leave breadcrumbs when old paths may still
be used.
