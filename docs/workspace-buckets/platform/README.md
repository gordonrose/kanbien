# Platform Bucket

This bucket is for runtime SaaS product and backend/app platform artifacts.

Use it for documentation that governs or describes:

- auth, users, tenants, roles, permissions, and authorization behavior
- APIs, persistence, migrations, jobs, assets, and durable data rules
- app behavior that matters independently of the harness
- source-independent platform planning records that are still active before
  they move into implementation, data dictionary, API contract, or feature docs

Current subfolders:

- `page-shell-planning/`
  Planned platform feature seam for governed page-shell planning.

Do not use it for:

- Product Discovery interview flow or packet-generation rules
- design-system lab artifacts
- repo-wide git, standards, or agent-governance records
- historical notes retained only for traceability

Before moving legacy files here, inspect references and leave a breadcrumb at
the old path when unknown dependencies may still exist.
