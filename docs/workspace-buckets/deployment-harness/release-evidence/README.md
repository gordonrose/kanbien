# Release Evidence

Trial release evidence records live here while the deployment harness is still
in discovery.

Use this folder for production-like deployment notes that capture source
revision, artifact identity, target runtime, migration evidence, rollout
evidence, smoke verification, rollback target, and known gaps.

Do not store secret values, access keys, session tokens, or private provider
configuration in release evidence records.
