# Discovery Harness Bucket

This bucket is for artifacts that help turn ideas, interviews, requests, and
planning conversations into governed work.

Use it for documentation that governs or describes:

- Product Discovery packets and interview rules
- Product Request flow and backlog models
- Technical Steering, Story Breakdown, Task Breakdown, and related handoffs
- planning artifact generation and validation behavior
- discovery-facing harness runtime plans while they are still discovery-owned
- future portable repo-mapping harness product ideas before they become
  governed implementation scope

Do not use it for:

- backend implementation truth
- design-system proof artifacts
- repo-wide git or standards guardrails
- historical examples that should not be copied into new work

Before moving legacy files here, inspect references and leave a breadcrumb at
the old path when old Product Request or planning artifacts still point there.

Current future-work folders:

- `harness-platform-boundary-map/` for an exploratory portable repo-mapping
  harness idea that should become Product Discovery or Technical Steering work
  before implementation.
