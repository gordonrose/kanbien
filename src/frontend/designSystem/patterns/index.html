Pattern Families

Governed Pattern Families

These are the recurring navigation behaviours people rely on across the app, even when they are not yet packaged as reusable components.

Pattern

Breadcrumb

Helps people understand where they are, recover the path they took, and stay oriented when space gets tight.

Pattern

Search Shell

Gives people a clear, consistent place to search within the current workspace without the shell feeling crowded.

Pattern

Context Nav

Helps people move around the current section, keeping the most important destinations and tools close at hand on both desktop and mobile.

Pattern

Navigation Shell

Sets the overall navigation structure so people can move confidently between major areas without relearning the interface on each page.
