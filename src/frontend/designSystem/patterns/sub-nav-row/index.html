Contract Highlights

What This Pattern Governs

The row itself is the contract: breadcrumb should yield first, search should stay centered and bounded, and the shell should remain stable under pressure.

Layout

Shared row container

Breadcrumb occupies the leading slot while search stays in the centered slot instead of turning into ad hoc page-local placement.

Pressure rule

Breadcrumb yields first

Long breadcrumb labels should collapse or compact before the search shell loses its governed width or alignment.

Adoption

Page chrome reuse

This pattern exists so every page family can inherit one honest secondary-chrome relationship instead of negotiating breadcrumb and search from scratch.
